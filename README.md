---

## ✨ Features

- 🎨 **Modern Design System**: Sleek glassmorphism effects, dynamic dark/light theme switching, and smooth gradients.
- ⚡ **Performance & Animations**: Powered by Next.js App Router, Framer Motion transitions, particle canvas background, tilt cards, and magnetic interactive buttons.
- 📱 **Fully Responsive**: Mobile-first responsive layout seamlessly optimized across desktop, tablet, and mobile displays.
- 🚀 **Interactive Sections**:
  - **Hero Section**: Dynamic typewriter role switching and active status badge.
  - **About Me**: Comprehensive background summary, education at IIIT Bhopal, and technical interests.
  - **Skills Showcase**: Categorized skill cards (Frontend, Backend, Languages, Cloud & DevOps, AI/ML tools).
  - **Projects Showcase**: Interactive project cards with live demo & GitHub links.
  - **Achievements & Experience**: Contributor highlights (GSSoC '24, ATF '24, etc.).
  - **Coding Profiles**: Quick links to LeetCode, Codeforces, CodeChef, and GitHub.
  - **Contact Section**: Direct email & social links for quick connection.

## 🚀 Getting Started Locally

### Prerequisites

Ensure you have Node.js (v18 or higher) and npm installed.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/deeya-meena/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000) to see the live portfolio site.
